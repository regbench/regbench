# `v5d_verdicts.jsonl`

Per-item v5d audit dispositions for the audited subset of the released pool.

## Schema

Each line is a JSON object with:

| Field | Type | Description |
|---|---|---|
| `id` | string | Stable item id (matches `data/{dnv,pilot}.jsonl`) |
| `domain` | string | `dnv_ru_ship` \| `dnv_ru_ship_pilot` |
| `tier` | int | Chain depth |
| `v5d_disposition` | string | `PASS` (no defect found), `FAIL` (substantive defect confirmed by v5d), or `UNCERTAIN` (v5d flagged for further review) |
| `v5d_reason` | string | Free-text rationale produced by the auditor model |
| `auditor_model` | string | `gpt-5.4` |
| `reasoning_effort` | string | `xhigh` |

## Coverage

| Pool | Released | v5d audited (this file) | Coverage |
|---|---:|---:|---:|
| DNV main (`R500_` / `F500_`) | 499 | 242 | 48.5% |
| DNV pilot (`P50_`) | 47 | 47 | 100% |
| Basel III §217 (`B_`) | 281 | 0 | — |

The DNV main coverage corresponds to the **combined 200-item DNV TRAIN+TEST audit pool** (148 TRAIN + 100 TEST, with 48 overlap accounting for the 242 unique audited ids) and a partial T2 audit slice — the items used for v5d calibration in the paper. The remaining 257 DNV items in the released pool passed through v5d gating but their per-item audit logs were not retained in a single consolidated file at release time.

The 47-item pilot subset is fully audited.

Basel III §217 items have v5d-flagged-subset adjudication logs and a v5d-pass-set sample (paper §3.5) but the full per-item v5d disposition log for the 281-item Basel pool is not redistributed; per-fact audit reads on the audited slice can be regenerated by re-running `pipeline/audit/auto_gt_audit.py` against the released items with the locked v5d prompt at `prompts/v5d_audit.md`.

## Re-running the audit

To regenerate per-fact v5d reads on any released item, point the audit driver at the released pool with the locked prompt:

```bash
cd pipeline/audit
python auto_gt_audit.py \
    --items ../../data/dnv.jsonl \
    --prompt ../../prompts/v5d_audit.md \
    --auditor-model gpt-5.4 \
    --reasoning-effort xhigh \
    --out v5d_audit_rerun.jsonl
```

Note that the audit driver uses the cache layer in `pipeline/audit/llm_client.py`; results are deterministic at `temperature = 0` and identical to the paper's reported figures up to model-vendor non-determinism.
